Убедитесь, что у вас установлена версия Node.js >= 18.0.0.

```bash

git clone [https://github.com/ваш-аккаунт/ваш-проект.git](https://github.com/ваш-аккаунт/ваш-проект.git)

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
